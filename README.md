# 锦格 · 文物织锦意匠图工作站

把博物馆老织锦照片处理成可上机的格子意匠图：

1. **照片导入页**：上传文物照片，或生成带地面真值的传统纹样测试照片。
2. **经纬拉平页**：拖动布面四角校正斜拍与透视；Worker 估计经纬边缘周期和缓慢褶皱位移场。
3. **循环单元页**：自动估计经纬格距、整幅格阵和纹样基频循环；可手动修改经丝数、纬丝数和偏移。
4. **意匠图修改页**：Canvas 格子编辑器，支持画笔、取色、同色全局替换、缩放、撤销/重做、低可信格提示、PNG/JSON/CSV 导出和每色纬线用量估算。

拉平、找循环、叠合、归色和样片生成均通过 Vite Web Worker 执行；核心算法是不依赖 DOM/Canvas 的纯 TypeScript，因此同一套管线也直接在 Node/Vitest 验收测试中运行。

## 验收结果

当前仓库包含 5 种自造传统纹样：

- 团花镜 `round-flower`：56 × 56 循环
- 缠枝莲 `interlocking-lotus`：72 × 44 循环
- 如意云纹 `cloud`：52 × 52 循环
- 万字回纹 `meander`：64 × 32 循环
- 凤穿牡丹 `phoenix`：64 × 56 循环

每种纹样均以 3 × 3 个循环织造，再显式加入并标记：

- `wrinkle`：褶皱振幅，单位为经纬格距倍数；
- `oblique`：斜拍/透视强度；
- `fade`：褪色比例；
- `damage`：破洞与污渍面积比例；
- `yellow`：黄化程度；
- `colorBleed`：相邻颜色光学混合程度；
- `seed`：可复现随机种子。

`test/acceptance.test.ts` 对标准验收套片断言：

- 自动循环经、纬根数与人工地面真值之差均 **≤ 1**；
- 最优循环平移和色号置换后，每格颜色与老工艺员格阵一致率 **≥ 95%**。

`test/gallery.test.ts` 进一步对 5 种纹样 × 轻度/中度/重度 15 张样片执行同样断言。最近一次完整运行中 **24/24 测试通过**，标准验收套片一致率为 `0.9997–1.0000`。

性能测试构造 `7653 × 7840 = 60.0MP` 的 RGBA 照片并执行完整管线。最近一次单独运行：

```text
PERF 7653x7840 (60.0MP) total≈1.3s
     straight≈0.53s repeat≈0.62s color≈0.18s
```

在 `npm test` 并行运行、CPU 被其他测试文件占用时约为 3.8s，仍低于 10 秒要求。关键性能手段是：6000 万像素原图只参与一次/少量反向采样，重计算集中在约 1700–1900 长边的拉平分析图；浏览器导入交互图时会先生成长边 ≤2400 的工作图。

> 说明：仓库没有真实文物照片和老工艺员原图，因此测试中的“人工数出的经纬根数/意匠图”由可复现合成器生成并作为地面真值。接入真实照片后，四角和循环参数仍可在页面上人工修正，导出的 JSON/PNG 可作为工艺复核和上机数据交换基础。

## 处理管线

```text
文物照片 RGBA
  └─ estimateClothQuad            深色背景上的布面四边形粗检
      └─ straightenImage          单应矩阵反向投影 + 条带边缘匹配褶皱场
          └─ estimateGridGeometry 边缘投影自相关 + 梳状边界/格心对比度搜格数
              └─ detectRepeatFromGrid
                 ├─ 每格五点采样
                 ├─ OKLab 色度加权周期特征
                 └─ 高分位自相似评分找最小基频
                  └─ foldRepeats  多循环对应格稳健中位数，压制破洞污渍
                      └─ clusterColors
                         ├─ 确定性 k-means++
                         ├─ 多初值最小化惯性
                         └─ OKLab 低亮度权重，降低褪色/黄化导致的色族分裂
                          └─ PatternResult
                             ├─ Uint8Array 色号格阵
                             ├─ PaletteColor[] 传统色名/HEX/RGB
                             ├─ number[] 每色格数
                             └─ Float32Array 置信度
```

### 为什么能处理这些干扰

- **褶皱/透视**：四角单应先把布面映射成矩形；缓慢褶皱由水平/竖直边缘投影的条带位移场估计。默认最终归色更依赖多循环格点的稳健叠合，避免全局条带误匹配在强纹样上累积漂移。
- **破洞污渍**：同一循环在照片中出现多次。破洞通常只落在其中一两个循环，逐通道中位数会把暗色洞口和异常污渍作为离群值排除。
- **褪色黄化**：在 OKLab 中聚类，并降低亮度方向权重、提高色度方向权重；同时用多初值 k-means 防止大色族被缓慢褪色渐变劈成两簇。
- **相邻颜色混淆**：采样点避开格边，使用中心邻域中位数；归色后保留置信度，低可信格可在编辑器中高亮并由工艺员复核。
- **根数差一**：格距自相关给出初值，再用“边界能量高、格心能量低”的梳状评分在 ±8% 范围内精修整幅格数；周期检测后还会做 ±2 格二维叠合残差修正。

## 导出物

- **带格子 PNG**：每 8 格加深红色主格线，并输出行列编号，适合打印或贴入工艺单。
- **JSON**：完整色号矩阵、调色板、用量、循环几何和来源文件名。
- **weft-usage.csv**：每色色号、传统色名、HEX、格数、占比、出现行数和按“每格平均纬长（毫米）”折算的纬长米数；文件带 UTF-8 BOM，Excel 直接打开不乱码。

## 后续接真实文物照片的建议

1. 优先使用正射/少畸变镜头，并在布边放置比例尺；当前纬长估算需要工艺员输入真实格距。
2. 对特别强的局部褶皱，可在拉平页调整实验性褶皱强度，或在循环页微调经/纬根数与起点。
3. 若文物使用已知纬线色卡，可把 `clusterColors` 的自由聚类替换为给定色卡的最近色约束；UI 已保留 HEX/传统色名和人工改格能力。
4. 6000 万像素以上图片建议继续保持“原图仅几何反投影、分析在缩小图、导出按原格阵矢量/高倍栅格化”的策略。
